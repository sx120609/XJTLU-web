# 阶段 0.5 完成与验收记录

## 本阶段结果

- 市集和学习内容的公开关联用户统一使用最小公开字段，不再返回 `username`。
- 全站搜索改用统一 `authOptional`，可识别现有 HttpOnly Cookie 会话和 Bearer 兼容请求。
- 学生实体商品新交易改为购买意向、预订、校内面交、双方确认；平台费固定为 0。
- 学生商品支付回调、支付发起、退款后台、结算、提现资料和佣金配置均被冻结；历史表和只读记录保留。
- 付费数字资料、数字品类创建/恢复和相关前端入口被冻结；免费原创内容的后端文件/版本能力保留，供阶段 4 改造。
- `/jwxt`、`/schedule`、旧学习资料页面和卖家结算中心均提供兼容重定向。
- Android、HarmonyOS 默认入口统一到 `/academic`；Flutter 主导航使用 `/academic` 和 `/market`，同时识别旧教务深链。
- 63 段不可回放的旧迁移原样归档；建立当前 PostgreSQL Schema 基线和阶段 0.5 增量迁移。
- 登录页、认证 Store、记住账号密码和现有登录体验按用户明确要求保持原样，相对原版本无内容差异。学校密码持久化风险继续记录，不在本阶段擅自修改。
