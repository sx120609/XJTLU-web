## 3. 环境门禁

### 3.1 PostgreSQL 集成测试

执行 `npm run test:integration` 时，预检确认 `127.0.0.1:55433/xjtlu_web` 没有可用的隔离 PostgreSQL 实例，因此测试在连接数据库前正确退出，集成用例没有被误报为成功。本机同时没有 Docker、`psql`、`pg_ctl` 或 `initdb`，未为了通过检查引入 Beta 级数据库运行时。

发布环境必须依次执行：

```powershell
npm run db:migrate --prefix server
npm run db:status --prefix server
npm run test:integration --prefix server
npm run db:verify:baseline --prefix server
npm run db:verify:backup --prefix server
```

以上命令全部通过后，才能勾选发布工作流的最后一项。

付费学习资料在生产环境仍采用显式开关。隔离环境完成创作者审核、付款凭证、交付、评价、退款和申诉 UAT 后，生产配置必须设置 `PAID_LEARNING_MATERIALS_ENABLED=true` 才会开放新付费订单；不能把开发环境默认值当作生产配置。

### 3.2 浏览器视觉回归

前端预览服务能够构建并启动，但当前自动化浏览器运行环境没有可用浏览器实例，因此没有伪造页面级视觉通过结论。发布前需使用桌面端和移动端真实浏览器检查：首页、实物市集、求购、学习资料、我的交易信用和运营后台。

## 4. 重点回归边界

- 学习资料保持付费交易，不进入免费实物交易口径；
- 普通市集评价仅允许实体订单，避免资料订单重复评价和重复积分；
- 手动完成与超时自动完成资料订单都会给买家、创作者记入一次积分；
- 历史回填只为实体订单发放实体交易积分，数字订单不会误领；
- 积分余额最低为 0，违规撤销按实际扣除额补偿；
- 待处理举报不直接降权，只有已确认有效的治理结果影响热门；
- 热门浏览信号封顶并按时间衰减，不能靠单一流量无限抬升；
- 统一信誉公开聚合结论，具体限制、申诉和积分流水只对本人或运营可见；
- 产品活动只记录日期、入口、来源和次数，不记录学号、密码、内容、关键词或原始 IP。
