# 阶段 2：校内交易闭环核验报告

核验日期：2026-07-19（Asia/Shanghai）

## 完成范围

- 将出售商品补齐为结构化信息：品牌、型号、使用时间、瑕疵、配件、是否支持测试、可交易时间、校区、公共面交地点、有效期和联系方式可见规则。
- 将求购从 `MarketItem.listingType=wanted` 拆为独立 `WantedPost`，提供独立列表、详情、发布、编辑、续期、结束、响应、接受和拒绝流程。
- 新增 `TradeIntent`，新交易不再复用历史支付报价语义；卖家接受后创建无支付 `reserved` 预约。
- 新增 `WantedResponse`，既可关联卖家公开在售商品，也可创建只向求购者展示的定向商品。
- 新增商品、求购、意向和预约的自动过期处理；过期预约会释放商品并恢复仍有效的求购。
- 支持面交时间地点、取消原因、爽约登记、买卖双方分别确认、完成后双方评价和交易历史。
- 新增卖家公开交易主页、商品/求购二维码分享，以及后台商品/求购审核和过期内容管理。
- 首页和全局搜索已改用独立求购数据源；市集出售频道不再混入旧求购记录。
- 历史支付、退款、结算相关后端记录和只读兼容路径保留；新学生商品交易仍禁止平台支付。

- 活动迁移：6 段。
- 当前公共 Schema：80 张基础表。
- 新增核心表：`TradeIntent`、`WantedPost`、`WantedResponse`。
- 空库迁移基线演练通过：从 6 段活动迁移创建 80 张表，并二次执行确认无待应用迁移。
- 实例测试完成后，`phase2_` 测试用户和测试帖子均为 0；没有遗留测试交易数据。
- Prisma schema 校验通过；客户端恢复使用稳定的 library engine，常规构建不会在开发服务运行时重复覆盖引擎文件。

- 服务端 TypeScript 生产编译：通过。
- Web `vue-tsc` + Vite 生产构建：通过，共转换 2877 个模块。
- 全量单元/回归测试：53/53 通过。
- 全量集成测试：4/4 通过。

- 真实数据库 + 临时 HTTP 服务闭环实例：通过。
  - 商品发布 → 买家意向 → 卖家接受 → 校内预约 → 买家确认 → 卖家确认 → 完成 → 评价。
  - 求购发布 → 卖家定向响应 → 求购者接受 → 预约 → 取消 → 求购恢复为可继续响应。

## 安全与兼容核验

- 市集、求购、搜索和交易关联用户对象不返回 `username`/学号。
- 商品和求购均要求明确的校区、公共面交地点和时间信息；意向/响应要求可交易时间。
- 新预约不创建平台支付、退款、提现或结算动作；历史财务回调保持冻结。
- 旧 `/market/publish` 继续重定向到出售发布；旧 `listingType=wanted` 查询入口重定向到独立求购频道。
- 登录页、凭据加密、鉴权 Store、教务 Store 和登录流程在阶段 2 未改动。
