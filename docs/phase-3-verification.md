# 阶段 3 验收记录：可信与安全

日期：2026-07-18

## 验收结论

阶段 3 已完成并通过验收，可以进入阶段 4。改造沿用既有用户、校园 SSO、商品、求购、预约、评价与后台权限体系，没有重写登录流程，也没有恢复学生商品的平台支付。

## 已完成范围

### 1. 校园身份与信用档案

- 复用 `User.studentSso` 作为校园身份核验来源，管理员/版主身份按既有角色体系识别。
- 新增公开信用档案与本人信用档案接口，展示信用分、完成交易、评分、好评率、取消、爽约和生效处理数量。
- 本人可在“我的交易 → 校园身份与信用”查看完整生效处理和申诉结果；公开主页只显示汇总，不暴露处罚原因详情。
- 个人页增加“校园身份与交易信用”入口，卖家商品页和公开卖家页展示信用状态。

### 2. 联系方式隐私

- 新增 `MarketContactCard`，联系方式使用 AES-256-GCM 加密保存，同时保留脱敏展示值。
- 联系方式不进入商品、求购、搜索、公开用户或后台概览序列化结果。
- 提交购买意向时不再提前创建交易会话；卖家接受后才创建并绑定预约会话。
- 只有有效预约的买卖双方能解密查看联系方式；旁观者、未接受意向、已取消/过期预约均不能查看。
- 历史支付订单的可读性保留，新增学生交易仍使用线下直接结算。

### 3. 禁售规则与内容复核

- 新增数据库可配置 `MarketSafetyRule`，初始规则覆盖代考/替考、处方药、烟草电子烟、管制刀具、博彩、贷款套现、账号身份和金融信息交易。
- 公开内容出现微信、手机号、QQ 号等站外联系方式时进入人工复核；求购响应在接受前禁止填写联系方式。
- 新建、编辑、续期商品与求购，以及定向响应均经过统一规则服务；禁售命中直接拒绝，复核命中进入 `reviewing`。
- 管理后台可新增、编辑、启停和删除规则，规则不硬编码在页面中。

### 4. 举报、处罚、申诉和审计

- 举报扩展到商品、求购、用户和具体交易，禁止举报自己并阻止重复待处理举报。
- 新增 `MarketViolation`、`MarketAppeal`、`AdminActionLog`。
- 后台支持警告、限制发布、限制交易、撤销处理、通过/驳回申诉；到期限制会自动失效。
- 管理动作写入审计日志，日志详情会过滤联系方式、账户、邮箱、手机号、令牌、密码和密文字段。
- 后台市集页增加“信用处理与申诉”“禁售规则”“管理日志”，并保留原商品/求购审核和历史交易查看。

### 5. 页面安全提示

- 商品、求购和预约继续强调校内公共区域见面、当面验货、不要提前转账、不要提供验证码或账户密码。
- 联系方式弹窗明确仅限当前已接受交易使用。
- 用户、求购和交易均提供举报入口，保持原有靠浦卡片、颜色、按钮、品牌标识和导航风格。
